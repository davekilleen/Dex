# Dex agent instructions

This is an installed Dex vault, not the dex-core development checkout.

Before starting any task in a Dex workspace, read the complete root `CLAUDE.md`.
It is the source of truth for Dex's persona, setup, safety rules, user profile,
custom instructions, and product behavior.

If `CLAUDE.md` is missing at the workspace root, fail loudly and stop. Do not
guess, continue, or make changes without those instructions.
